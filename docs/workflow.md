# Loop / Graph：半導體製程 Wiki 教學系統

## 設計目的
提供高中生與大一學生可持續累積的繁體中文製程教材。來源、Wiki 和簡報可逐項追溯，避免只生成漂亮卻沒有來源的內容。

## 工作流
討論新議題 → 取得可靠來源 → 摘要 ingest → **檢查點 A** → 更新 Wiki → 審查教學順序 → 生成／更新 HTML → **檢查點 B** → GitHub Pages 發布

### 迴圈
- 資料欄位缺失、來源重複、未提供來源網址 → 返回 ingest。
- 教學內容超出來源或重要概念衝突 → 返回查證與整理。
- 來源無法連到 Wiki 或網頁操作失敗 → 返回建置修正再測試。
- 一次只新增一個 SNN ID，既有 ID 不得重新使用。

## 一次執行記錄（2026-11-23）
- 起始 ingest：S01–S08，8 份來源摘要。
- 產物：8 篇 Wiki Markdown 與 HTML，11 頁教學 HTML 簡報。
- 來源對應：每個主要教學頁面底部有 Wiki ID，連到對應條目；條目再連回官方原始來源。
- 基本驗證：檢查 8 個 JSON 主題 ID、來源 URL、Wiki 條目及投影片的來源 ID。
- 自動檢查與人工瀏覽器測試分開紀錄；GitHub Pages 部署與外部連結須另做線上檢查。

## 反思
最容易出錯的節點是從摘要轉成教學投影片時的內容對照。先前只在簡報產生後檢查，較容易漏掉未入庫的概念或錯誤來源 ID。於是把驗證往前移至 ingest 階段，檢查 ID、URL 和欄位，並規定簡報每頁需能回溯 Wiki 條目。這讓新增資料時的錯誤能更早被攔截。
